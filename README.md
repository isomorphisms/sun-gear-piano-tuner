# Sun-gear piano tuner

Fine-control mechanical piano tuning tool. First deliverable: interchangeable
**square and eight-point star** tuning-pin sockets. Gear reduction **not yet chosen**.

## CAD: two equally supported adapter variants

| Artifact | Square | Eight-point star |
|---|---|---|
| Independent STEP prototype | [square_v1.step](cad/sun_gear_adapter_square_v1.step) | [star_v1.step](cad/sun_gear_adapter_star_v1.step) |
| FreeCAD-native model | Generated by [`cad/generate_models.FCMacro`](cad/generate_models.FCMacro) | Same macro |
| Parametric source | [`cad/freecad_adapter.py`](cad/freecad_adapter.py) | Same source |

The FreeCAD macro generates both **editable `.FCStd` Part Design models**,
including independent barrel/pilot pads, four-edge or sixteen-edge tapered
subtractive loft, and reference envelope. Outputs appear in `build/freecad/`.
`cad/adapter_geometry.py` centralizes the shared dimensions. A STEP preview is
*not* the FreeCAD feature-history model.

## Measured project envelope

- Maximum axial depth **4.000 in / 101.6 mm**.
- Exposed tuning pin available for gripping **0.500 in / 12.7 mm**.
- Nominal prototype uses a 10-mm grip target and 30-mm external adapter height;
  its top is at z=32.7 mm, leaving 68.9 mm of nominal axial room *before*
  bearings, housing and gears. **Width and clearances remain unmeasured.**

The opening dimension (7.05 mm) is **unverified**; the commercial #2 label is
not a drawing tolerance. Fit has to be tested against a real pin. The Ø8 pilot
is only a geometry placeholder, **not a qualified torque coupling**. Do not
apply tuning torque through a printed fit-check piece.

## Actual FreeCAD regression tests

```sh
bash tests/run_freecad.sh
```

That command **requires a real FreeCAD runtime** and fails if it cannot find one.
It checks both Part Design trees, validity, socket openings, blind roofs, axial
envelope, recompute, `.FCStd` reopen and STEP round-trip. A passing runner
exports **actual FreeCAD `.FCStd` and STEP files** for both variants to
`build/freecad-test/models/`; CI retains them as downloadable artifacts. See
[`docs/testing.md`](docs/testing.md) and the
[CI workflow](.github/workflows/freecad-native.yml).

**Status:** The original adapter v1 passed its 8 native FreeCAD tests on
FreeCAD 0.19 in CI (run 45054873747). The drive v2 suite passed **13/13**
native tests in [run 45065941001](https://github.com/isomorphisms/sun-gear-piano-tuner/actions/runs/45065941001), including six pitch-layout exports. Actual pin fit,
torque transmission, manufactured involute teeth and backlash remain unverified.

The existing [v0 star macro](cad/sun_gear_adapter_v0.FCMacro) and
[v0 STEP](cad/sun_gear_adapter_v0.step) are retained as historical references.
The v1 designs replace them as the current study; both square and star are
unselected alternatives.

See [`docs/adapter_design_notes.md`](docs/adapter_design_notes.md) for earlier
measurements, tuning-pin notes and gear concepts.

## Drive v2 — three reduction pitch studies (no mechanism selected)

[Drive calculations and evidence limits](docs/drive_tradeoffs.md) compare
4:1 planetary, 5:1 planetary and a 6:1 folded two-stage spur train. All
three have FreeCAD-native **pitch-envelope** reference assemblies using either
square or eight-point star adapter, for **six** editable `.FCStd` documents.

```sh
bash tests/run_freecad.sh
```

The native suite also tests the six drive references and exports their `.FCStd`
and reference-only `.step` files under `build/freecad-test/drives/` after passing.
Run `cad/generate_drive_models.FCMacro` in FreeCAD to export them manually.
These layouts do **not** contain manufactured teeth, rated bearings, output
coupling or quantified backlash. Lateral piano clearance is still unknown.

The adapter-only native suite was verified on FreeCAD 0.19 in
[GitHub Actions run 45054873747](https://github.com/isomorphisms/sun-gear-piano-tuner/actions/runs/45054873747);
**Drive v2 CI:** 13/13 tests PASS in [run 45065941001](https://github.com/isomorphisms/sun-gear-piano-tuner/actions/runs/45065941001). This proves reference geometry and serialization, not a working gearbox.
